# @sendoutcards/quantum-design-ui

quantum-design-ui is the component library for quantum design.

---

## Installation

`yarn add @sendoutcards/quantum-design-ui`

## Usage

Any of the components from QDS can be imported like so:

```jsx
import React from 'react'
import { PrimaryButton } from '@sendoutcards/quantum-design-ui'

const Example = () => {
  return (
    <PrimaryButton type="normal" title="Example Button" colorVariation="blue" />
  )
}
```
